# Changelog

## [1.0.0] - 2026-06-29

### Added
- Initial release of Elenty.app - Comprehensive social communication platform
- Social features: posts, stories, comments, likes, following system
- Advanced calling features: voice calls, video calls, international calls
- Real-time messaging with media sharing and voice messages
- Group conversations and chat management
- Live streaming capabilities
- Video reels and content creation tools
- Beauty filters and camera effects
- Challenge and trend system
- Notifications system
- User profiles and follower management
- Firebase integration for authentication and data storage
- LiveKit integration for WebRTC calls and live streaming
- Twilio integration for international calls
- Multi-language support (Arabic and English)
- Dark mode support
- Web, iOS, and Android platforms support

### Fixed
- Security: Removed exposed API keys from .env.example
- Configuration: Unified duplicate project configurations
- Development: Added comprehensive development tools (ESLint, Prettier, Jest)
- Type Safety: Enhanced TypeScript configuration for strict type checking
- Build: Updated package.json with proper build and deployment scripts

### Technical Stack
- React Native 0.79.1
- Expo 53.0.4
- TypeScript 5.8.3
- Zustand 5.0.6
- React Query 5.83.0
- Expo Router 5.0.3
- NativeWind 4.1.23
